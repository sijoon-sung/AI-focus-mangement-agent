# 1~2분 안에 계획을 끝내기 위한 메모 화면

실제 소요 시간을 검증했다는 뜻이 아니라 사용자 흐름의 목표다. 메모장처럼 적고, 첫 일을 골라 바로 시작한다.

1. **오늘 뭐 하고 싶어요?**에 생각나는 대로 적는다. 메모는 0.7초 입력 중단 후 로컬 DB에 자동 저장한다.
2. **할 일 정리해줘**를 누른다. 짧은 줄별 목록은 즉시 정리하고, 자유 문장은 로컬 Ollama의 `qwen3.5:4b`로 정리한다.
3. 제안이 괜찮으면 **좋아, 시작하자**. 작업을 저장하고 첫 배치 작업의 세션을 시작한다. 이미 진행 중인 세션이 있다면 그 세션을 유지한다.

원본 메모는 AI 결과로 덮어쓰지 않는다. 시간·종류·우선순위 입력이나 별도의 완료 조건 작성은 필수가 아니다. ‘조금 고칠래’, ‘오늘 여유 바꾸기’, ‘이유·변경 내용 보기’는 필요할 때만 사용한다. 외부 메모장 파일 연동은 이번 구현에 포함하지 않았다.

## 시간과 배치

- 기본 가용 시간은 4시간이고 화면에 표시한다. 한번 바꾸면 기억한다. 실제 캘린더의 빈 시간을 조회하는 기능은 아니다.
- 비슷한 제목의 완료 작업을 우선 참고하고, 충분하지 않으면 같은 종류의 완료 작업을 참고한다. 사용 가능한 기록 3개 이상일 때 세션 시간 중앙값을 사용한다.
- 부족하면 기존 예상값 또는 임시 25분을 사용한다. 근거를 펼치면 자료 수와 예상 출처를 볼 수 있다. 기록은 집중 시간이나 작업 품질 측정값이 아니다.
- 우선순위와 메모 순서에 따라 배치하고 작업마다 15% 또는 최소 5분 여유를 둔다. 시간에 들어오지 않는 작업은 다음으로 표시한다. 큰 작업을 AI가 임의로 완료 처리하거나 강제로 쪼개지 않는다.
- 대기·완료·선행 작업 미완료는 시작 대상에서 제외한다. 선행 작업이 오늘 끝날 것이라는 가정으로 후속 작업을 자동 배치하지 않는다.
- 이는 이력 기반 통계와 규칙이며 신경망으로 학습한 소요 시간 예측기는 아니다. 실제 개인 데이터에서 예측 오차는 아직 평가하지 않았다.

선택적으로 목록에 `! 메일 답장 [15분]`처럼 쓸 수 있다. `!`는 먼저 할 일, `[15분]`은 사용자가 정한 예상이다. 이 문법을 알아야 쓸 수 있는 UI로 만들지 않았다. `#`로 시작한 줄과 `[x]` 줄은 목록 추출에서 제외하며, `[x]`로 기존 앱 작업을 완료 처리하지 않는다.

## 수정과 기록 보존

같은 제목은 기존 작업을 연결하므로 반복 적용해도 중복되지 않는다. 이전 목록의 한 줄을 비슷한 제목으로 바꾼 경우는 수정 후보로 연결하고 ‘기존 작업 수정 포함’을 표시한다. 여러 줄을 모호하게 바꾸거나 전혀 다른 제목으로 바꾸면 신규 작업 후보로 처리한다. ‘이유·변경 내용’에서 원래 제목을 볼 수 있다.

줄을 지워도 기존 작업·세션은 삭제하지 않는다. 지웠던 제목을 다시 추가하면 저장된 연결을 찾아 쓴다. 완료 작업은 자동으로 다시 열지 않는다. 반복 작업을 새 기록으로 남기려면 날짜 등으로 구별하거나 기존 계획 화면에서 다시 예정으로 변경한다.

메모 수정 이후 예전 미리보기를 적용하지 못하게 막는다. Qwen 응답을 기다리는 중 원본 메모를 바꾸면 예전 결과는 버린다. Qwen은 계획 초안만 만들고 작업 생성·완료·시작을 직접 실행할 권한이 없다. 시작 버튼을 눌러야 계획에 반영한다.

## 개인정보·장애 처리

메모는 계획 데이터와 함께 로컬 SQLite에 보관되며 다음 날에도 유지한다. 전체 초기화로 삭제할 수 있다. 활동 보관일 설정은 이 메모를 자동 삭제하지 않는다. DB 암호화는 아직 없다.

문장 정리를 요청한 경우에만 메모 본문을 `127.0.0.1:11434`의 Ollama로 전달한다. 원격 API나 cloud fallback은 없다. 카메라·화면 캡처는 사용하지 않는다. 앱 종료 시 대기 중인 결과를 UI에 적용하지 않는다. 이미 처리 중인 Ollama 요청은 timeout/완료까지 서버에서 지속될 수 있다.

Qwen이 실패하면 오류 팝업으로 계속 막지 않고 줄별 목록으로 사용할 수 있다고 안내한다. 정리 결과는 누락·우선순위 오류가 있을 수 있어 원본을 유지하고 바로 수정할 수 있게 한다.

## 2026-10-14 확인 결과

- 기존 기능 포함 **28개 테스트 통과**: 반복 적용, 제목 수정 시 세션 유지, 삭제 후 재연결, 완료 유지, 선행 조건, 이력 기반 예상, 예산, UI 적용과 오래된 미리보기 거부.
- 합성 메모로 실제 로컬 Qwen 호출. 첫 지시문은 할 일을 누락했다. 지시문 개선 후 논문 읽기/보고서 작성/메일 답장 3개와 명시한 15분을 추출했다. ‘메일 먼저’ 우선순위는 보존하지 못했다. 형식 검사만으로 의미적 완전성을 보장하지 않으며 사용자 수정 경로를 유지한다.
- 예제 데이터로 앱 화면을 렌더링하고 버튼·입력창·목록의 배치를 확인했다.
- 1~2분 계획 완료 여부, 개인 예상 시간 정확도, 자동 배치 만족도는 후속 실제 사용 평가 항목이다.
