# Planwise 사용 안내

## 설치

Python 3.11 이상과 Tkinter가 필요합니다. Windows Python 설치의 Tcl/Tk 옵션을 포함하세요.

```bash
python -c "import tkinter, sqlite3; print(tkinter.TkVersion)"
python -m local_agent
```

저장소 폴더에서 실행합니다. 기존 requirements 파일 설치는 필요 없습니다. Windows는 `Start-Planwise.cmd` 더블클릭도 가능합니다. Python이 PATH에 있어야 합니다.

별도 데이터 위치:

```powershell
python -m local_agent --data-dir "$env:LOCALAPPDATA/Planwise"
```

기본값은 프로젝트의 `local_data/planwise.sqlite3`입니다. Git에서 제외됩니다. 동기화 폴더라면 위치를 바꾸세요. 다른 데이터 폴더는 별도 작업 목록을 사용합니다.

## 하루 사용 흐름

1. **작업 추가:** 이름·완료 조건·다음 행동·예상 분·우선순위·종류를 입력합니다. 선행 작업 하나를 지정할 수 있습니다.
2. **다음 작업 추천:** 가용 시간을 입력합니다. 이유는 ‘근거와 회고’ 탭에서 확인합니다. 자동 시작은 하지 않습니다.
3. **시작/복귀:** 작업을 시작합니다. 기존 세션이 있으면 복귀 메모를 남긴 뒤 전환합니다. 대기 또는 선행 작업 미완료면 시작하지 않습니다.
4. **중단 메모:** 진행 상황과 다음 행동을 남깁니다. 세션 시간이 멈춥니다.
5. **대기 설정:** 몇 분 뒤 다시 확인할지 지정합니다. 앱 상단 알림이며 실제 실행 완료 감지가 아닙니다.
6. **대기 해제/완료 확인:** 직접 상태를 확인합니다. 잘못 완료했으면 ‘다시 예정으로’를 사용합니다.
7. **회고:** 오늘 완료 수·세션 시간을 확인하고 추천에 피드백을 남깁니다.

세션 시간은 시작~중단 구간입니다. 중단하지 않은 휴식도 포함되며 집중 시간·진척도 측정값은 아닙니다. 앱 종료 시 세션은 중단됩니다. 다시 실행하면 직접 복귀합니다.

## 활동 수집과 개인화

개인정보 탭에서 켜면 Windows 앱을 6개 범주로 분류하고 5분 이상 입력 없음 여부를 15초마다 기록합니다. 앱 자체의 창은 제외합니다. 수집이 꺼져도 계획·세션·추천은 작동합니다.

범주 연결 확인:

1. 수집을 켜고 대상 앱에서 15초 이상 작업합니다.
2. 60초 안에 돌아와 작업을 선택합니다.
3. ‘최근 앱 범주를 선택 작업에 연결’을 누르고 실제 관련 여부를 확인합니다.

확인 기록이 충분하고 동률이 아닐 때 연결 후보를 표시합니다. 페이지별 구분과 자동 작업 전환은 없습니다. 추천 피드백은 평가 기록이며 모델을 자동 재학습하지 않습니다.

## 개인정보

- 제목·URL·키 입력 내용·클립보드·화면·카메라는 수집하지 않습니다.
- 활동·판단 기록은 기본 7일 보관하며 앱 실행 중 정리합니다.
- 계획·메모·세션·확인한 범주 연결은 직접 삭제 전까지 보관합니다.
- ‘활동 기록·범주 개인화 삭제’는 관측·범주 연결·판단·그 피드백을 삭제합니다. 세션 시간 기반 보정은 남습니다.
- 모든 개인화까지 지우려면 ‘모든 로컬 데이터 초기화’를 사용합니다.
- DB 자체는 암호화하지 않습니다. OS 계정 접근 권한을 따릅니다.
- 집계 내보내기는 오늘 완료 수·세션 시간·전체 작업 수·피드백 집계만 포함합니다.

## 문제 해결과 한계

- 실행 실패: Python/Tkinter 설치를 확인하세요. CMD 런처는 오류 때 콘솔을 유지합니다.
- 이미 실행 중: 같은 데이터 폴더를 사용하는 창을 닫으세요. 파일 잠금은 프로세스 종료 시 풀립니다.
- 관측 없음: 수집/제외 설정과 다른 앱 사용 여부를 확인하세요. 조회 불가능한 앱은 추정하지 않습니다.
- 대기 알림: 앱이 열려 있어야 하며 다음 15초 검사에 상단 표시됩니다. 트레이/OS 토스트는 미구현입니다.
- 시간 추정: 실제 업무량이 아닙니다. 예상 시간은 해당 작업의 전체 예상 시간이며 누적 세션을 차감합니다.
- 날짜: 마감일·오늘 배정은 미구현입니다. 가용 시간은 현재 구간의 예산입니다.
- 다른 OS: Tkinter 계획 UI는 사용 가능하나 관측은 Windows 전용이고 타 OS 실기 검증은 아직 없습니다.
