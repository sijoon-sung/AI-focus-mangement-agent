# 대학원 지원 포트폴리오 초안

상태: 연구 실행 전. 대괄호는 실제 결과로 채울 항목이다.

## 현재 사실대로 쓸 수 있는 설명

“MediaPipe와 ActivityWatch 정보를 LangGraph 피드백에 연결하는 집중 지원 프로토타입을 개발했다. 행동 기반 점수의 타당성과 사용자 간 일반화라는 한계를 확인하고, 자체 CNN 및 시간 합성곱 모델의 학습·평가 파이프라인으로 확장했다. 사용자 중복 검사, 검증 기반 모델 선택, 클래스 불균형 및 확률 보정 비교를 설계했다. 공개 데이터 실험은 진행 예정이며 인지적 집중력 측정을 입증한 것은 아니다.”

## 실험 후 작성 틀

1. 문제: 임계값 기반 눈·고개 점수는 사람과 환경에 따라 달라진다.
2. 질문: 처음 보는 사용자에서 시간 모델이 경량 CNN의 참여도 분류를 개선하는가?
3. 방법: TinyCNN·TinyCNN+TCN·ResNet18+TCN을 같은 분할과 입력으로 비교하고 가중 손실과 보정을 분석했다.
4. 결과: “[분할 조건]에서 3 seeds macro-F1 [평균±표준편차], balanced accuracy [값], 클래스별 recall [값]을 얻었다. E0 대비 E2 차이는 [값]이었다.”
5. 해석: 개선 또는 악화가 나타난 사례, 모델 크기와 처리 비용, 실패한 가설을 설명한다.
6. 한계: 라벨의 주관성·배경 의존·개발 환경으로의 도메인 이동·소수 클래스 불확실성.
7. 기여: 데이터 검증·학습 코드·실험 통제·오류 분석·재현 문서. 참고 문헌과 직접 수행한 수정·실험을 구분한다.

## 제출물

- 1페이지 요약: 문제, 방법 그림, 실측 비교표, 기여, 한계.
- 4~6페이지 연구 보고서: Introduction / Related Work / Method / Experiments / Limitations / Conclusion.
- GitHub: 설치·데이터·학습·평가 방법과 작은 결과 표.
- 2~3분 데모: 통합 후 출력·불확실/미검출 상태·지연·실패 사례.
- 면접 설명: scratch와 사전학습 비교 이유, 데이터 누출 방지, accuracy의 한계, 실패한 실험에서 배운 점.

“자체 CNN으로 SOTA 달성”, “집중력 95% 측정”, “새로운 CNN+TCN 알고리즘”, “개발 생산성 개선”은 현재 근거가 없다. 실제 수행과 검증을 넘어서는 표현을 쓰지 않는다. 대학원 연구 경험으로서의 가치는 새로운 레이어 조합보다 질문·통제·재현·해석의 연결에 있다.

컴퓨터비전 연구실에는 일반화와 시간 모델, 효율적 ML에는 성능·비용, HCI에는 개입 유용성과 사용자 통제를 중심으로 설명한다.
